# StableFlow 项目说明报告

> 写给非程序员看的完整说明。不需要任何技术背景就能看懂。

---

## 一句话说明

**StableFlow 是一个用数字货币买卖服务的平台，钱由代码看管，不经过任何中间人。**

你可以把它理解为"区块链版 Fiverr"——自由职业者（设计师、开发者、写手）在平台上挂出自己的服务，客户用 USDC（数字美元）付款。钱不是直接打给卖家，而是先锁在一个智能合约里，卖家每完成一个阶段，买家确认后才释放对应的钱。

---

## 用的什么技术？

| 项目 | 具体是什么 | 通俗解释 |
|------|-----------|----------|
| **区块链** | Base Sepolia（测试网） | Coinbase（美国最大交易所）建的"快速通道"，手续费约 $0.01/笔，2 秒确认 |
| **代币标准** | ERC-20 | 以太坊上最通用的代币格式，就像人民币的"纸币标准" |
| **支付币种** | USDC | 数字美元，1 USDC = 1 美元，由 Circle 公司发行，价格稳定 |
| **合约语言** | Solidity 0.8.20 | 写智能合约的编程语言 |
| **安全库** | OpenZeppelin v5.6.1 | 业界最权威的合约安全组件，就像建筑用的"国家标准建材" |

---

## 核心合约：StableFlowEscrow

这是整个项目的"心脏"，388 行代码，负责管理所有资金流转。

### 它能做什么？

| 功能 | 谁能用 | 大白话解释 |
|------|--------|-----------|
| **创建订单** | 买家 | 买家下单，USDC 锁入合约，卖家能看到钱已经到了 |
| **交付里程碑** | 卖家 | 卖家说"我完成了这个阶段"，通知买家来验收 |
| **释放里程碑** | 买家 | 买家确认满意，钱释放给卖家 |
| **自动释放** | 卖家 | 买家 14 天不理不踩，卖家可以自动拿钱（防止被拖死） |
| **发起争议** | 买卖都行 | 任何一方觉得不对劲，可以发起争议 |
| **仲裁解决** | 仲裁员 | 仲裁员按比例分钱（比如五五开、七三分），不是非黑即白 |
| **超时退款** | 买家 | 争议 30 天没解决，买家自动全额退款 |
| **紧急暂停** | 管理员 | 发现漏洞时一键冻结所有操作 |

### 关键参数

- 平台手续费：**2%**（Fiverr 的十分之一）
- 买家确认期限：**14 天**（超时卖家可自动收款）
- 争议解决期限：**30 天**（超时买家自动退款）
- 最低订单金额：**1 USDC**
- 最多里程碑数：**10 个**

### 安全防护

合约用了四层安全机制：
1. **防重入攻击** — 阻止攻击者反复调用函数把钱提走
2. **权限控制** — 只有管理员才能暂停合约
3. **紧急暂停** — 发现问题一键冻结
4. **安全转账** — 使用 OpenZeppelin 标准的代币转账方式

## 架构图

```
用户（浏览器 + MetaMask 钱包）
        │
        │  连接钱包、发交易
        ▼
   Base Sepolia 区块链
        │
        ▼
   StableFlowEscrow 合约
   ┌─────────────────────┐
   │  创建订单            │
   │  里程碑交付/释放      │
   │  争议解决            │
   │  超时退款            │
   │  紧急暂停            │
   └─────────┬───────────┘
             │
             ▼
        USDC 代币
     （1 USDC = 1 美元）
```

**最大的特点：没有后端服务器。** 用户的浏览器直接和区块链通信，不需要任何服务器中转。资金操作全部在链上完成，任何人都可以查验。

## 和 Fiverr/Upwork 比有什么优势？

| 对比项 | Fiverr / Upwork | StableFlow |
|--------|----------------|------------|
| **手续费** | 10-20% | 2% |
| **资金透明度** | 存在平台"黑箱"里 | 在链上，任何人可查 |
| **跨境支付** | 3-7 天到账，有汇率损失 | USDC 即时结算，无汇率损失 |
| **争议处理** | 平台单方面裁决 | 仲裁员按比例分配 |
| **平台跑路风险** | 有（2022-2023 多家暴雷） | 无（资金在合约里，平台碰不到） |
| **地域限制** | 部分国家无法使用 | 加密货币无国界 |
| **付款方式** | 全款一次性付 | 里程碑分批释放（更安全） |

### 核心差异化：里程碑托管

不是"全款一次性付"，而是按项目阶段分批释放。举个例子：

一个 500 USDC 的 Logo 设计项目：
- 阶段 1（概念草图）：30% = 150 USDC
- 阶段 2（修改完善）：40% = 200 USDC
- 阶段 3（最终交付）：30% = 150 USDC

每个阶段完成后，买家确认才释放对应的钱。这样买家不会"钱给了活没干完"，卖家也不会"活干完了钱拿不到"。

## 当前开发状态

### 已经做好的

- 智能合约 V3（功能完整，已通过编译）
- 合约测试（309 行测试代码，覆盖所有场景）
- 前端网页（首页、浏览服务、创建服务、我的订单、我的销售）
- 中英文双语支持
- 暗色赛博朋克 UI
- 部署脚本（一键部署到测试网）
- 微信公众号发布工具

### 还没做好的

- 合约还没真正部署到链上（目前是占位符地址）
- 前端和合约之间的链上交互还没打通（目前用 localStorage 模拟）
- 没有后端服务（数据存在浏览器本地，换浏览器就丢失）
- 没有安全审计
- 只在测试网，还没上主网

### 如果要上线还需要

1. 安全审计（找专业公司审计合约）
2. 部署合约到 Base 主网
3. 打通前端和合约的链上交互
4. 加后端服务（存服务列表、订单数据）
5. 用户系统（注册/登录）
6. 合规审查

## 总结

StableFlow 解决的是真实痛点（高手续费、慢结算、不透明），目标市场规模巨大（全球自由职业经济 $1.5 万亿），技术完成度较高（合约 V3 + 完整前端）。距离真正上线还需要安全审计、合约部署、后端服务等工作。
