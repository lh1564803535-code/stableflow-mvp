# Anthropic 同时吃了亚马逊、谷歌、微软、马斯克的算力，我大脑宕机了三秒

Anthropic 做了一件事。

同时跟亚马逊、谷歌、微软、马斯克签了算力协议。

这四家的关系是什么？互相竞争。

而 Anthropic 在中间，跟每一方都笑着握手。

我第一反应是：这不科学。

第二反应是：等等，这很科学。

因为它的 CEO Dario Amodei 紧接着说了一句——

ARR 增速 80 倍，希望别再涨了，太离谱。

<!-- 📷 图1：Anthropic 大会现场 或 Dario 发言截图 -->

---

先看数字，你就知道为什么我宕机了。

| 合作方 | 算力/金额 | 到位时间 |
|---|---|---|
| 亚马逊 | **5 吉瓦**（2026 底先落 1 吉瓦） | 进行中 |
| 谷歌 + 博通 | **5 吉瓦** | 2027 陆续投产 |
| 微软 + 英伟达 | **3000 亿美元** Azure 算力 | 已签约 |
| SpaceX（马斯克） | **300 兆瓦**、22 万张 GPU | 本月内 |
| Fluidstack | **5000 亿美元**基建投入 | 已官宣 |

这些数字加起来是什么概念？

就是你去吃自助餐，龙虾、和牛、帝王蟹、鹅肝全拿了，还顺手把厨房的原材料也打包了。

别的 AI 公司还在排队等 GPU，Anthropic 已经把整个算力超市搬空了。

---

为什么所有人愿意给它钱？

三个原因。

**第一，它不站队。**

亚马逊投了 40 亿美元，是最大的单一投资方。但 Anthropic 也用谷歌的 TPU、微软的 Azure、马斯克的 Colossus。

这就像一个球员同时跟四支球队签了合同，每支球队都觉得"它最终会选我"。

但 Anthropic 的骚操作是：它从来不选。

它让每一方都觉得"我们关系最好"，同时从每一方拿到最想要的东西——算力。

渣男行为，但渣得很有效。

**第二，它有东西可卖。**

ARR 增速 80 倍不是空话。

就在这次开发者大会上，Claude Code 调用限制直接翻倍，5 小时变 10 小时，高峰时段不再削减额度，API 速率限制全面放开。托管智能体上线三大新能力，Claude Code 连更十余项功能。

投资人不怕花钱，怕花完钱没东西。

Anthropic 直接把东西怼脸上了。

**第三，"安全"这张牌太好用了。**

Dario 一直在讲 AI 安全。在所有人都在卷"谁更强"的时候，Anthropic 卷的是"谁更安全"。

这让它在监管层面获得了天然好感。欧盟的 AI 法案、美国的行政令——所有跟安全相关的政策讨论里，Anthropic 都是被邀请上桌的那个。

"安全"不是口号，是准入证。

你可以说它是人设，但这个人设，值几百亿美元。

<!-- 📷 图2：Anthropic 算力合作全景图 -->

---

现在说最精彩的部分：马斯克为什么把 Colossus 给 Anthropic。

马斯克联合创立了 OpenAI，后来被排挤出局。OpenAI 从非营利变成了微软的摇钱树。马斯克气到起诉。

然后他做了 xAI，做了 Colossus 数据中心，训练了 Grok。

但他做这些，不只是为了自己用。

他做这些，是为了证明一件事：没有你 OpenAI，我也行。

现在他把 Colossus 的全部算力给了 Anthropic——一家跟 OpenAI 正面竞争的公司。

这不是商业合作，这是地缘政治。

马斯克的意思很明确：我不只是自己打 OpenAI，我还支持所有打 OpenAI 的人。

而 Anthropic 恰好是那个最值得支持的对手——产品在跑、增速在涨、人设干净、路线跟 OpenAI 完全不同。

所以你看，Anthropic 拿到马斯克的算力，不是因为它左右逢源。

是因为在 AI 赛道的派系战争里，它恰好站在了一个所有人都需要的位置上。

---

再看 Dario 那句话。

ARR 增速 80 倍，希望别再涨了，太离谱。

表面是凡尔赛，实际上是三层信号：

对投资人说：我们不缺需求，我们缺算力——你们的钱花得值。

对竞争对手说：我们的增速你们追不上——别追了。

对员工说：别骄傲，算力瓶颈才是真正的敌人——我们还没赢。

一个餐厅老板说"客人太多了厨房忙不过来"，他不是在抱怨。

他是在告诉你：**这家店值得排队。**

---

来，吵三个架。

**算力多 ≠ 模型好。**

算力是基础设施，不是护城河。谁都能买 GPU，但不是谁都能训出好模型。如果下一代 Claude 翻车，再多的卡也救不了。

**同时吃所有人 = 所有人都是备胎。**

亚马逊投了 40 亿，但 Anthropic 也用谷歌的 TPU。亚马逊不会永远容忍这种暧昧。当它要求 Anthropic 做选择的时候，这盘棋就变了。

**安全人设能撑多久？**

当商业利益和安全承诺冲突时，Dario 会选哪个？当一个大客户要求 Claude 放松安全限制来完成一个利润丰厚的项目，Anthropic 会说不吗？

这个问题现在不用回答。但它迟早要回答。

---

最后。

Anthropic 同时跟所有人合作，不是因为它左右逢源。

是因为 AI 这个赛道太大了，没有任何一家能单独吃下。亚马逊有钱但没有最好的模型，谷歌有算力但缺 To B 的信任，微软有 OpenAI 但也在分散风险，马斯克有 Colossus 但需要盟友。

每一方都需要 Anthropic。而 Anthropic 需要所有人的算力。

这个局能维持多久？不知道。

但真正的考验还没来。当算力不再是瓶颈，当所有人都有足够 GPU 的时候，Anthropic 凭什么还是被选中的那个？

<!-- 📷 图3：Dario 发言截图 -->

答案只有一个：**模型本身够不够好。**

其他都是暂时的。

算力会过剩，补贴会停止，盟友会变卦。

只有模型好不好这件事，是用户每天都在投票的。

Dario 知道这件事。

所以他凡尔赛的那句话，本质上是在说：

**我们现在赢了，但我们还没赢。**
