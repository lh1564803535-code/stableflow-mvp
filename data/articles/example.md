# 先说结论

如果你的目标是**提高发文效率**，最合理的第一步不是直接全自动发布，而是先把排版和草稿生成自动化。

## 为什么这样做

- 你可以保留最终审稿权
- 公众号编辑器的格式问题可以先在本地预览阶段解决
- 后续要接 AI 摘要、标题建议、封面建议也更自然

## 一个最小闭环

1. 写好 Markdown 原稿
2. 生成适合公众号的 HTML
3. 本地预览排版
4. 上传素材并创建草稿

> 自动化真正节省的不是“点击发布”那一下，而是每次重复整理格式、替换图片、补元数据的时间。
