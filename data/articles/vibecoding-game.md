# Vibe Coding 是假的创业，真的游戏

**——以及为什么 99% 的人做出的东西，将毫无价值**

---

我前几天看到 Naval 说了一句话，大意是：

> Vibe coding 就像电子游戏，但它是无限地图、真实奖励的那种。

我第一反应是：说得太对了。

第二反应是：这也太危险了。

---

## 我自己的故事

几周前，我用 AI 做了一个区块链项目。

一个人。零后端经验。从空白文件开始。

它叫 StableFlow——一个用 USDC 付款的自由职业者服务市场。支持里程碑托管、钱包连接、中英文切换、暗黑主题。整个产品，从第一行 HTML 到能跑起来，全是我一个人和 AI 对话出来的。

那天晚上我搞到凌晨四点。

不是因为赶 deadline。

是因为停不下来。

## 为什么停不下来

Naval 说得很准：Vibe coding 的反馈机制跟游戏一模一样。

你给一句话，它给你一个结果。

你改一个颜色，页面立刻变。

你说"把按钮往左移"，它就往左移。

你说"不对，还是移回来"，它也不嫌你烦。

传统开发像工程——理解需求、设计方案、写代码、调试、验证。每一步都有阻力，每一步的满足感都来得很慢。

Vibe coding 像游戏——输入很轻，反馈很快，试错成本几乎为零。

你想要什么，它就给你什么。

不满意？重来。

不喜欢？换路线。

你的想法被实现的速度，快到你的创造力都来不及刹车。

**这就是游戏让人上瘾的核心机制：它永远在你能力边缘给你奖励。**

不会难到让你放弃，也不会简单到让你无聊。

你现在会做一个按钮了？好，下一个挑战是做一个完整页面。

你会做页面了？好，试试加上区块链。

你会接区块链了？好，试试做国际化。

它不断升级，你不断上分。

**唯一的区别是：游戏的奖励是假的，vibe coding 的奖励是真的——至少看起来是。**

---

## 但这里有个陷阱

我做完 StableFlow 之后，冷静了大概半天。

然后我问了自己一个问题：

**这个东西，除了我，还有谁会用？**

答案很诚实：大概率没有人。

不是因为它做得不好。是因为一个没有后端经验的人用 AI 做的区块链 demo，本质上就是一个**精致的空壳**。

它能跑，但不能扛。

它能看，但不能用。

它能演示，但不能上线。

**Vibe coding 最大的幻觉就是：把"做出来了"等同于"做得有价值"。**

## Naval 说的"真实世界奖励"，有一半是真的

Naval 说 vibe coding 跟普通游戏不一样，因为它是图灵机在底层跑，理论上你可以构建任何东西，而且它有现实世界的意义。

这句话对了一半。

你确实能构建任何东西。但"能构建"和"构建出来有价值"之间，隔着一个太平洋。

就像你能用乐高搭出任何形状，但绝大多数乐高作品最终的归宿是拆掉放回盒子。

**Vibe coding 降低了造东西的门槛，但没有降低判断什么东西值得造的门槛。**

---

## 真正的问题

以后所有人都能 vibe coding 了。

这意味着什么？

意味着"能快速做东西"这件事本身，将不再稀缺。

当工具免费、速度趋同、AI 无限耐心，真正的稀缺变成了：

- **什么值得做**——你能识别出真正的问题吗？
- **为谁做**——你知道谁会为此掏钱吗？
- **为什么这样做**——你的方案跟别人的方案有什么本质区别？
- **怎么做得让人愿意用**——你知道什么是好的体验吗？

这四个问题，AI 一个都回答不了。

---

## 所以 99% 的人做出的东西，将毫无价值

这不是悲观。这是数学。

当所有人都能造东西，造出来的大部分东西一定是垃圾。

就像当所有人都能拍照，99% 的照片不会被看第二遍。

当所有人都能拍短视频，99% 的视频播放量不超过 100。

当所有人都能写公众号，99% 的文章——嗯，这个例子太近了，不说了。

## 但这不是坏事

换个角度看。

Vibe coding 真正做的事情，是把**创造的权力**从 0.1% 的人手里，交到了 1%-3% 的人手里。

Naval 说得好：对于有创造力、有自驱力、有清晰愿景的人，现在没有任何东西挡在你和你的原型之间了。

你不需要找合伙人。

你不需要说服投资人。

你不需要等三个月的开发周期。

你想要什么，今晚就做出来。

**这确实像 Minecraft——Notch 一个人写出来的。**

<!-- 📷 图片：Minecraft 经典截图 或 Notch 的照片，呼应"一个人的视野" -->
![Minecraft - 一个人的视野](在这里放 Minecraft 经典截图)

那个画面看起来像 20 年前的东西，但它没妥协。它是一个人的完整视野。没有人跟他说"这个方块不好看，改成圆的"。

Vibe coding 最大的价值，不是让你更快地做出跟别人一样的东西。

是让你做出**只有你会做的东西**。

---

## 最后

我用 AI 做了一个区块链市场，凌晨四点做完的，很爽。

但冷静下来我知道，那不是一个创业，那是一场游戏。

一场非常逼真的游戏。

它的反馈是真的，它的多巴胺是真的，它的成就感也是真的。

但它的价值——取决于做完之后，你有没有停下来问自己：

**这东西，除了我，还有谁需要？**

如果你答得上来，那你就不是在玩游戏，你是在造东西。

如果答不上来，没关系，至少你玩得很开心。

**只是别把游戏当成创业就行了。**
